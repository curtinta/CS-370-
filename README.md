# CS-370-Project Overview: Pirate Intelligent Agent (Treasure Hunt Game)
For this project, I worked on building a pirate intelligent agent using reinforcement learning and neural networks. I was given a starter codebase that included the game environment, the state and action definitions, and the overall structure of the Jupyter Notebook. The .py files handled the environment logic, reward system, and movement rules, and I was instructed not to modify those files.

My main responsibility was completing the Q‑Training Algorithm section inside the Jupyter Notebook. I created the code that defined the deep Q‑learning model, the training loop, the epsilon‑greedy exploration strategy, the memory replay system, and the update rules for the neural network. I also added comments and explanations to make the code readable and maintainable. The final result was a functional agent that learns how to navigate the map and reach the treasure.
